# Business Model Canvas — NegocioCerto.AI

## Segmentos de clientes
- Profissionais autônomos.
- Microempreendedores.
- Pequenos prestadores de serviços.
- Negócios locais que usam WhatsApp para vender.

## Proposta de valor
- Centralizar pedidos de orçamento.
- Reduzir esquecimentos.
- Mostrar o próximo passo.
- Usar IA para preparar o atendimento.
- Manter o fechamento humano no WhatsApp.

## Canais
- WhatsApp.
- Instagram.
- Conteúdo educativo.
- Indicação.
- Prospecção direta.

## Relacionamento
- Onboarding curto.
- Interface simples.
- Sugestões de IA.
- Suporte humano no início.
