# Testes do MVP

## Teste 1 — Landing

**Esperado:** proposta entendida rapidamente.

- [x] Headline clara.
- [x] CTA principal.
- [x] Benefícios.
- [x] Fluxo explicado.

## Teste 2 — Cadastro

**Esperado:** cadastrar uma oportunidade.

- [x] Nome.
- [x] Serviço.
- [x] Descrição.
- [x] Orçamento.
- [x] Prazo.
- [x] Validação.

## Teste 3 — Dashboard

**Esperado:** identificar prioridades.

- [x] Contadores.
- [x] Lista.
- [x] Status.
- [x] Próxima ação.

## Teste 4 — WhatsApp

**Esperado:** abrir conversa com contexto.

- [x] Mensagem gerada.
- [x] CTA WhatsApp.

## Teste 5 — Responsividade

Validar manualmente em:

- [ ] Android.
- [ ] Desktop.
- [ ] Tablet.

## Teste real recomendado

Usar com pelo menos 1 prestador real durante alguns dias e registrar:

- oportunidades cadastradas;
- follow-ups realizados;
- tempo economizado;
- conversas iniciadas;
- vendas geradas;
- feedback qualitativo.
