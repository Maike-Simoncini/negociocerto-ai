# Mercado — metodologia de validação

O projeto evita apresentar estimativas hipotéticas como dados oficiais.

## TAM

Definir a população total de pequenos negócios/prestadores potencialmente atendidos.

## SAM

Recortar para negócios que:

- vendem serviços;
- recebem solicitações digitais;
- utilizam WhatsApp;
- têm necessidade de acompanhar oportunidades.

## SOM

Começar por um recorte operacional que possa ser alcançado diretamente, por exemplo:

- uma cidade/região;
- um segmento profissional;
- rede de indicação;
- audiência própria.

## Próximo passo

Substituir as premissas por fontes públicas e dados observados durante a validação.

Fontes que podem ser consultadas na etapa seguinte:

- IBGE;
- Sebrae;
- DataSebrae;
- dados oficiais sobre empresas e empreendedorismo;
- pesquisas de uso digital de pequenos negócios.

O objetivo do MVP é testar comportamento real, não produzir uma projeção financeira definitiva.
