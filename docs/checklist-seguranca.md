# Checklist de Segurança

Antes de publicar:

- [ ] Nenhuma API key está no Git.
- [ ] Nenhum token está no Git.
- [ ] Nenhuma senha está no Git.
- [ ] `.env` está no `.gitignore`.
- [ ] `.env.example` contém apenas nomes de variáveis.
- [ ] Secrets foram configurados no ambiente apropriado.
- [ ] Regras de acesso do banco foram revisadas.
- [ ] Dados de clientes não ficam públicos.
- [ ] O painel administrativo possui controle de acesso adequado.
- [ ] URLs públicas não expõem dados sensíveis.
- [ ] Não existem credenciais em screenshots.
- [ ] O projeto foi revisado antes da publicação.
